# 部署指南

## 1. 生产拓扑

```
客户端 ──► Nginx ──► uvicorn x N ──► PostgreSQL
              │            │
              │            └──► Redis
              └──► /static 静态托管（前端）
```

- **Nginx**：托管 `frontend/` 静态文件；`/api`、`/admin`、`/` 反代到 uvicorn；`/api/chat/stream` 需关闭缓冲（`proxy_buffering off;`）保证 SSE 实时性。
- **uvicorn**：`--workers N`（N ≈ CPU 核数）；生产建议配 systemd 或 supervisor 守护。
- **PostgreSQL + Redis**：`docker compose up -d` 一键起，或在云上购买托管实例。

## 2. 环境变量

```env
DATABASE_URL=postgresql+psycopg://ragent:ragent@localhost:5432/ragent
REDIS_URL=redis://localhost:6379/0
LLM_API_KEY=sk-xxx
JWT_SECRET=<强随机串，务必修改>
```

初始化（迁移 + 建管理员 + 灌知识库）：

```bash
alembic upgrade head            # 生产用 Alembic 迁移（首次需 alembic revision --autogenerate）
python -m scripts.create_admin
python -m scripts.seed_demo_kb  # 或通过后台「知识库」上传企业资料
```

## 3. 定时任务

每日运营报表建议用 cron / 计划任务执行：

```
0 1 * * * cd /opt/ragent && .venv/bin/python -m scripts.generate_daily_report
```

## 4. 高并发优化清单

| 手段 | 实现 | 建议 |
| --- | --- | --- |
| 多进程 | uvicorn `--workers N` | N=CPU 核数，单机 8 核可支撑较高 QPS |
| 高频缓存 | Redis 问答缓存 | `QA_CACHE_TTL` 调大；预热热门问题 |
| 限流 | IP 限流 | `RATE_LIMIT_PER_MINUTE` 按需调整 |
| 向量检索 | Chroma 本地文件 | 生产可将 CHROMA_DIR 挂载到 SSD / 持久卷 |
| 连接池 | SQLAlchemy pool | 已按 PostgreSQL 配置 pool_size=10 / overflow=20 |
| SSE 缓冲 | Nginx `proxy_buffering off` | 避免流式响应被攒批 |
| 静态资源 | Nginx 直接托管 | 减轻应用压力 |

## 5. Docker 一键部署

```bash
docker compose up -d                 # PG + Redis
docker build -t ragent-py .
docker run -d --name ragent -p 8000:8000 \
  --env-file .env \
  -v ragent-data:/app/data \
  ragent-py
```

> 注意：`.env` 中 `DATABASE_URL`/`REDIS_URL` 指向宿主机地址时，容器内请改用 `host.docker.internal`，或直接让容器加入 compose 网络。

## 6. 常见问题

**Q：SSE 流式在 Nginx 后不实时？**
设置 `proxy_buffering off;` 并 `proxy_cache off;`。

**Q：首次启动 embedding 模型下载慢？**
本地 ONNX 模型首次使用需下载；可将 `EMBEDDING_PROVIDER=hash` 零依赖兜底，或提前把模型放入 `EMBEDDING_MODEL_DIR` 后启动。

**Q：转人工工单没有生成？**
检查数据库已 `init_db`/`alembic upgrade`；转人工触发需要命中四条规则之一（用户要求 / 投诉 / 低置信 / 连续未解决）。

**Q：多 worker 下缓存不一致？**
Redis 模式下多进程共享缓存与限流；`REDIS_ENABLED=false` 仅适合单进程开发。
