# 意图标注指南

本项目的意图识别采用「**小样本池 + LLM 零样本 few-shot**」设计：小样本池注入提示词做少样本分类，无需训练即可上线；样本积累到一定规模后可导出训练集做 PEFT 微调，进一步提准。

## 1. 意图体系

定义在 `agent/intent_samples.py` 的 `INTENT_LABELS`：

| 意图代码 | 含义 | 典型表达 |
| --- | --- | --- |
| `greeting` | 问候/寒暄 | 你好、在吗 |
| `query_order` | 查询订单/物流 | 订单查一下、快递到哪了 |
| `refund` | 退款/退货 | 我要退款、怎么退货 |
| `repair` | 报修/维修 | 冰箱坏了、怎么报修 |
| `complaint` | 投诉 | 我要投诉、态度差 |
| `after_sales` | 售后/质保/换货 | 质保怎么算、能换新吗 |
| `invoice` | 发票 | 怎么开发票 |
| `coupon` | 优惠券 | 优惠券怎么用 |
| `member` | 会员/账号 | 会员有什么权益 |
| `human` | 转人工客服 | 转人工 |
| `other` | 其他 | 兜底 |

## 2. 扩充样本池

编辑 `agent/intent_samples.py` 的 `INTENT_SAMPLES`，追加 `("问法", "意图")`：

```python
INTENT_SAMPLES: list[tuple[str, str]] = [
    ...
    ("充电器不充电", "repair"),      # 新样本
    ("能开专票吗", "invoice"),
]
```

注意事项：

- **均匀覆盖**各意图（建议每类 ≥ 10 条）。
- 多写**口语化、模糊表达**（如「卡了」「退了」），少写书面语，模型更适应真实客服。
- 一条样本只表达一个意图；多意图句子拆开标注。

## 3. 验证与调优

运行意图单测确认改动不破坏既有识别：

```bash
pytest tests/test_intent.py -q
```

识别链路：关键词规则（`RULE_KEYWORDS`，高置信低延迟）→ LLM few-shot。若某问法规则误判，优先调整规则关键词；若 LLM 分类不准，补充样本。

## 4. 导出训练集 / 微调

导出 JSONL 训练集：

```bash
python -m scripts.export_intent_samples
# 输出 data/intent_samples.jsonl：每行 {"text": "...", "intent": "..."}
```

**可选微调**：积累数百条真实客服标注后，可用 `LLaMA-Factory` / `PEFT` 对小型中文模型（如 Qwen2.5-1.5B）做 LoRA 意图分类微调，替代提示词分类，获得更低延迟与更稳的置信度输出。微调后的模型可通过 `LLM_BASE_URL` 挂到 OpenAI 兼容服务上，无需改动代码。

> 微调推理时，建议让模型输出固定 JSON 结构 `{"intent": "...", "confidence": ...}`，与 `agent/intent.py` 的解析逻辑保持一致。

## 5. 置信度与分流

`INTENT_CONFIDENCE_THRESHOLD`（.env）控制低置信转人工；规则命中固定高置信，LLM few-shot 置信度低于阈值时自动倾向澄清或转人工，避免「答非所问」。
